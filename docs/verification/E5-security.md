# E5 security checklist (SEC-01 to SEC-08)

What E5 changes against PRD §8.2, with the evidence that each item still holds; items E5 does not touch keep the
evidence of `E1-security.md` to `E4-security.md`. The suites are `pnpm check`, `pnpm test:integration`,
`pnpm test:daemon`, `pnpm test:e2e`, `pnpm test:nfr`, `pnpm test:soak` and `pnpm verify:artifact`, with the macOS
test host up (P-71) where they include it.

| Item     | What E5 adds                                | Evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Status |
| -------- | ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| SEC-01.1 | Shell integration, events, OS notifications | The injected scripts only print OSC 133 and OSC 7 and set prompt hooks; protocol 4's events travel on the existing bridge; OS notifications are posted by the main process through Electron's `Notification`. None opens a socket; `no-listeners.spec.ts` still finds no TCP listener or UDP socket in the app's processes or the daemons                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Met    |
| SEC-02.2 | Protocol 4's events                         | `SessionChange::Activity` goes only to clients the core already accepted by peer identity, and only to those that negotiated protocol 4 (`broadcast_activity`, `ACTIVITY_PROTOCOL`); a protocol-3 client gets nothing new (`shell_integration.rs` `tells_protocol_4_clients_when_a_command_finishes_and_older_ones_nothing_us_5_3`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Met    |
| SEC-04.3 | The injected scripts                        | They are embedded in `trcd` (`include_str!`), so the binary's SHA-256 check covers them; the core writes them under `<root>/shell-integration/<digest>/`, folders 0700 and files 0600 inside the 0700 install root (`shell_integration/install.rs`), so no other user can change what a shell runs                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Met    |
| SEC-05.1 | Marks in saved scrollback                   | Saved history gains only OSC 133 marks before the rows they mark (P-74): the prompt, output, end and exit code, never a command line; fish's `cmdline_url` is dropped (P-75). The files keep their 0600 modes                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       | Met    |
| SEC-06.2 | Marks, OSC 1337, events and announcements   | No mark acts: OSC 133 and `SetMark` only record rows, read by the commands the user runs (`command-marks.ts`, `marks.rs`); exit codes parse only as up to 10 digits. Of OSC 1337, only `CurrentDir`, `RemoteHost` and `SetMark` are read, each body capped at 4,096 bytes and cancelled by CAN or SUB; `File=` and every other key are ignored (`iterm.rs`, P-69); a folder named for another host is not taken (`osc7.rs` `reported_here`). Announcements strip control characters. Forged marks can't flood: the holder reports a finished command and a bell each at most once a second, the app plays at most one command cue a second per session, and a session posts at most one OS notification of each kind every 10 s, the main process refusing more than one a session every 2 s (P-82) | Met    |
| SEC-06.1 | Copy last command output                    | Only the app's own command copies (Option-Command-C, the menu or the palette); the main process writes the clipboard for `clipboard:copy` at most once every 500 ms and up to 16 MiB (`pacer.ts`, P-82). No key-press gate, as VoiceOver and Voice Control activate the command without one. OSC 52 keeps its per-host switch and is unchanged                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Met    |
| SEC-06.4 | OS notifications                            | They hold the session's own name or its shell, its host and the event, never output or a title a program set (P-76, P-81); `notifications:post` is validated (title ≤ 256, body ≤ 1,024, key ≤ 512 characters, nothing else); the session's name is stripped of control characters, as every name is; choosing one only opens its session                                                                                                                                                                                                                                                                                                                                                                                                                                                           | Met    |
| SEC-07.1 | Shell integration on hosts                  | The scripts install with the daemon under the user's install root, with no administrator step, and are removed with it                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              | Met    |
| SEC-08.1 | Logs                                        | The core logs only that the scripts could not be written, with the I/O error; the holder logs nothing about marks or commands; no command line, environment value (such as the `ENV` or `ZDOTDIR` the scripts restore) or output is logged                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Met    |
| Tooling  | The macOS test VM                           | As in E4 (D-53): only the VM's SSH is forwarded, to `127.0.0.1:2230`; the VM and its base image are deleted at the end of E5 (P-71)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 | Met    |
