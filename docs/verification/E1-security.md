# E1 security checklist (SEC-01 to SEC-08)

Each item of PRD §8.2 that E1 delivers, with the evidence that it holds. "Automated" means a test that fails if the
item breaks; the suites are `pnpm check` (unit), `pnpm test:integration` and `pnpm test:daemon` (test hosts),
`pnpm test:e2e`, `pnpm test:nfr` and `pnpm verify:artifact` (the packaged app, in the release workflow).

| Item     | Requirement                                                        | Evidence                                                                                                                                                                                                                                                        | Status    |
| -------- | ------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| SEC-01.1 | No TCP listener, loopback included, and no UDP socket              | `verify:artifact` launches the packaged app with every debugging switch and finds none (`tools/verify-artifact`); release builds strip `--remote-debugging-port` (`debugging-guard.ts`); `test/e2e/no-listeners.spec.ts`; the dev server binds `127.0.0.1` only | Met       |
| SEC-01.2 | The daemon listens only on a 0600 socket in a 0700 directory       | `crates/trcd/tests/core_linux.rs`, `core.rs` (modes, `/tmp/trc-<uid>` fallback)                                                                                                                                                                                 | Met       |
| SEC-01.3 | Tests assert no listener after install, connect and create         | App: `no-listeners.spec.ts` (every process but main, and main only Playwright's loopback endpoints) plus `verify:artifact` for main in the release build; daemon: `core_linux.rs` checks `/proc/net` and `ss` for every `trcd` process                          | Met       |
| SEC-02.1 | The daemon rejects peers that are not its user                     | `core_linux.rs` other-user test, run as root in containers (`pnpm test:daemon`); `holder_process.rs`                                                                                                                                                            | Met       |
